How it works: HMAC-SHA256(key = serverSeed, message = clientSeed:nonce:caseId), first 13 hex characters = a 52-bit number n, bucket = floor(n * 100000 / 2^52), the winner is the first item (in odds.json order) whose running total of weights is above the bucket. Full write-up in the README.
